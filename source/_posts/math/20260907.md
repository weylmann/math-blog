## 题目

将容量为 $N$ 的总体分为两层，第一、二层的容量分别为 $N_1$、$N_2$，现从这个总体中抽取容量为 $n$ 的样本，设第一、二层抽取的样本量分别为 $n_1$、$n_2$，$n_1 \geq 2$，$n_2 \geq 2$，且 $\dfrac{n_1}{N_1} = \dfrac{n_2}{N_2} = \dfrac{n}{N}$，记简单随机抽样下，总体中两个特定不同个体都被抽中的概率为 $P_0$；记按比例分层随机抽样下，同属第一层、同属第二层、分属两层的两个特定不同个体都被抽中的概率分别为 $P_1$、$P_2$、$P_3$．下列结论正确的是（　　）

A. $(N_1 - 1)(P_3 - P_1) = (N - 1)(P_3 - P_0)$

B. $(N_1 - 1)(P_3 - P_1) = (N_2 - 1)(P_3 - P_2)$

C. $N_1(P_3 - P_1) + N_2(P_3 - P_2) < 2N(P_3 - P_0)$

D. $N_1(P_3 - P_1) + N_2(P_3 - P_2) > 2(N - 1)(P_3 - P_0)$

<details>
<summary>参考解答</summary>

<strong>解析：</strong>

记 $k = \dfrac{n}{N}$（抽样比，$0 < k < 1$），则 $n_1 = kN_1$，$n_2 = kN_2$。

<strong>先写出各概率：</strong>

- 简单随机抽样中，容量为 $n$ 的样本包含两个特定不同个体，等价于再从其余 $N-2$ 个个体中抽 $n-2$ 个：

$$P_0 = \frac{\binom{N-2}{n-2}}{\binom{N}{n}} = \frac{n(n-1)}{N(N-1)} = \frac{k(kN-1)}{N-1}$$

- 同理，第一层内两点同被抽中：

$$P_1 = \frac{n_1(n_1-1)}{N_1(N_1-1)} = \frac{k(kN_1-1)}{N_1-1}$$

- 第二层内两点同被抽中：

$$P_2 = \frac{n_2(n_2-1)}{N_2(N_2-1)} = \frac{k(kN_2-1)}{N_2-1}$$

- 分属两层的两点独立抽取、各自入样：

$$P_3 = \frac{n_1}{N_1} \cdot \frac{n_2}{N_2} = k^2$$

<strong>核心恒等式：</strong>

$$P_3 - P_1 = k^2 - \frac{k(kN_1-1)}{N_1-1} = \frac{k^2(N_1-1) - k^2N_1 + k}{N_1-1} = \frac{k(1-k)}{N_1-1}$$

同理 $P_3 - P_2 = \dfrac{k(1-k)}{N_2-1}$；且

$$P_3 - P_0 = k^2 - \frac{k(kN-1)}{N-1} = \frac{k^2(N-1) - k^2N + k}{N-1} = \frac{k(1-k)}{N-1}$$

<strong>逐项判断：</strong>

<strong>A.</strong> 由上式立即得

$$(N_1-1)(P_3-P_1) = k(1-k) = (N-1)(P_3-P_0)$$

恒成立，A 正确。

<strong>B.</strong> 同理

$$(N_1-1)(P_3-P_1) = k(1-k) = (N_2-1)(P_3-P_2)$$

恒成立，B 正确。

<strong>C.</strong> 计算左边：

$$N_1(P_3-P_1) + N_2(P_3-P_2) = k(1-k)\left(\frac{N_1}{N_1-1} + \frac{N_2}{N_2-1}\right) = k(1-k)\left(2 + \frac{1}{N_1-1} + \frac{1}{N_2-1}\right)$$

右边：

$$2N(P_3-P_0) = \frac{2Nk(1-k)}{N-1} = k(1-k)\left(2 + \frac{2}{N-1}\right)$$

两边同除 $k(1-k) > 0$，比较剩余部分：

$$\frac{1}{N_1-1} + \frac{1}{N_2-1} - \frac{2}{N-1} = \frac{(N-1)(N_1+N_2-2) - 2(N_1-1)(N_2-1)}{(N_1-1)(N_2-1)(N-1)}$$

分子展开（利用 $N = N_1 + N_2$）：

$$(N-1)(N-2) - 2(N_1N_2 - N_1 - N_2 + 1) = N_1^2 + N_2^2 - N$$

由 $N_1, N_2 \geq 2$ 知 $N_1^2 - N_1 + N_2^2 - N_2 \geq 2 > 0$，即分子 $> 0$，故左边 $>$ 右边，选项 C 的"$<$"不成立，C 错误。

<strong>D.</strong> 由 C 的计算：

$$N_1(P_3-P_1) + N_2(P_3-P_2) = 2(N-1)(P_3-P_0) + k(1-k)\left(\frac{1}{N_1-1} + \frac{1}{N_2-1} - \frac{2}{N-1}\right) \cdot 1 > 2(N-1)(P_3-P_0)$$

（因为上式括号内 $> 0$），D 正确。

数值验证（取 $N_1=4, N_2=6, n=5$，$n_1=2, n_2=3$）：$P_0=\dfrac{2}{9}$，$P_1=\dfrac{1}{6}$，$P_2=\dfrac{1}{5}$，$P_3=\dfrac{25}{36}$，代入四项验证与上述结论一致。

<strong>答案：</strong>ABD
</details>
