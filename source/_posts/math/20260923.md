## 题目

若一个几何系统中任意两点间的距离的最大值称为这个几何系统的"径区"，例如圆的径区即为其直径。则：

（1）设 $ABC$ 是直角边长为 1 的等腰直角三角形，其中 $AB \perp AC$。分别以 $AB$、$AC$、$BC$ 为直径的三个圆构成一个几何系统，该系统的径区为 $\underline{\qquad}$；

（2）棱长为 2 的正方体 $ABCD-A_1B_1C_1D_1$ 的棱切球（与该正方体所有棱都相切的球）与三角形 $ACB_1$ 的外接圆构成一个几何系统，该系统的径区为 $\underline{\qquad}$；

（3）棱长为 2 的正方体 $ABCD-A_1B_1C_1D_1$ 中，正方形 $ABCD$ 的内切圆与正方形 $ADD_1A_1$ 的内切圆构成一个几何系统，该系统的径区为 $\underline{\qquad}$。

<strong>解析：</strong>

（1）三个圆的半径分别为 $\frac12$、$\frac12$、$\frac{\sqrt2}{2}$，圆心分别是 $AB$、$AC$、$BC$ 的中点 $D$、$F$、$E$。

<img src="/images/20260923_1.svg" width="50%">

先看两点分别在不同圆上的情形。设两圆圆心为 $X$、$Y$，半径分别为 $r_1$、$r_2$，则对圆上任意两点 $M$、$N$ 有 $MN \le MX + XY + YN = r_1 + |XY| + r_2$，当 $M$、$X$、$Y$、$N$ 依次共线时取到等号。由中位线定理，$DF = \frac{BC}{2} = \frac{\sqrt2}{2}$，$DE = \frac{AC}{2} = \frac12$，$EF = \frac{AB}{2} = \frac12$。于是

- 圆 $D$ 与圆 $F$ 上各取一点：$\frac12 + \frac{\sqrt2}{2} + \frac12 = 1 + \frac{\sqrt2}{2}$；
- 圆 $D$ 与圆 $E$ 上各取一点：$\frac12 + \frac12 + \frac{\sqrt2}{2} = 1 + \frac{\sqrt2}{2}$；
- 圆 $F$ 与圆 $E$ 上各取一点：$\frac12 + \frac12 + \frac{\sqrt2}{2} = 1 + \frac{\sqrt2}{2}$。

两点在同一个圆上时，最大距离即该圆直径，三个圆直径分别为 $1$、$1$、$\sqrt2$，都不超过 $\sqrt2 < 1 + \frac{\sqrt2}{2}$。

所以该系统径区为 $1 + \frac{\sqrt2}{2}$。

（2）棱切球的球心 $O$ 即为正方体的中心。棱长为 2，中心到各棱的距离为 $\sqrt{1^2+1^2} = \sqrt2$，故棱切球半径 $R = \sqrt2$。

三角形 $ACB_1$ 的三条边长都等于面对角线 $2\sqrt2$，所以它是正三角形，外接圆半径 $r = \frac{2\sqrt2}{2\sin 60^\circ} = \frac{2\sqrt6}{3}$，外心 $O_1$ 即该正三角形的中心。

<img src="/images/20260923_2.svg" width="50%">

以正方体中心为原点建立坐标系（各坐标轴与棱平行），可取 $A(1,-1,-1)$、$C(-1,1,-1)$、$B_1(-1,-1,1)$，于是 $O_1\left(-\frac13,-\frac13,-\frac13\right)$，$|OO_1| = \frac{\sqrt3}{3}$。

设 $N$ 为外接圆上任意一点，则 $ON = \sqrt{|OO_1|^2 + r^2} = \sqrt{\frac13 + \frac83} = \sqrt3$，即球心 $O$ 到圆周上任意一点的距离恒为 $\sqrt3$。

两点分别取在球上与圆上时，$MN \le OM + ON = \sqrt2 + \sqrt3$，当 $M$、$O$、$N$ 三点共线且 $O$ 在 $M$、$N$ 之间时取到等号；两点取在同一个几何对象上时，球面上两点最大距离为球直径 $2\sqrt2$，圆周上两点最大距离为圆直径 $2r = \frac{4\sqrt6}{3}$。

而 $\sqrt2 + \sqrt3 \approx 3.146 < \frac{4\sqrt6}{3} \approx 3.266$，所以该系统径区为 $\frac{4\sqrt6}{3}$。

（3）以 $D$ 为原点，$DA$、$DC$、$DD_1$ 所在直线分别为 $x$、$y$、$z$ 轴建立空间直角坐标系。

正方形 $ABCD$ 的内切圆在 $xDy$ 平面内，圆心为 $O_1(1,1,0)$，半径 1；正方形 $ADD_1A_1$ 的内切圆在 $xDz$ 平面内，圆心为 $O_2(1,0,1)$，半径 1。

<img src="/images/20260923_3.svg" width="58%">

设 $M(1+\cos\alpha,\ 1+\sin\alpha,\ 0)$ 在第一个圆上，$N(1+\cos\beta,\ 0,\ 1+\sin\beta)$ 在第二个圆上（$\alpha$、$\beta$ 为任意实数），则

$$MN^2 = (\cos\alpha - \cos\beta)^2 + (1 + \sin\alpha)^2 + (1 + \sin\beta)^2 = 4 + 2(\sin\alpha + \sin\beta - \cos\alpha\cos\beta)$$

注意 $\sin\beta - \cos\alpha\cos\beta = \sqrt{1+\cos^2\alpha}\,\sin(\beta - \varphi)$（辅助角公式），故

$$MN^2 \le 4 + 2\left(\sin\alpha + \sqrt{1+\cos^2\alpha}\right) \le 4 + 2\sqrt2\sqrt{\sin^2\alpha + 1 + \cos^2\alpha} = 8$$

即 $MN \le 2\sqrt2$。等号成立当且仅当两处放缩同时取等：由 $\sin\alpha = \sqrt{1+\cos^2\alpha}$ 得 $\alpha = \frac{\pi}{2}$（此时 $\varphi = 0$），再得 $\sin\beta = 1$，即 $\beta = \frac{\pi}{2}$。直接验证：此时 $M(1,2,0)$ 是 $BC$ 的中点，$N(1,0,2)$ 是 $A_1D_1$ 的中点，$MN = \sqrt{2^2 + 2^2} = 2\sqrt2$。

两点在同一个圆上时，最大距离即该圆直径 $2$，小于 $2\sqrt2$。

所以该系统径区为 $2\sqrt2$。

<strong>答案：</strong>（1）$\displaystyle 1+\frac{\sqrt2}{2}$；（2）$\displaystyle \frac{4\sqrt6}{3}$；（3）$\displaystyle 2\sqrt2$
