## 题目

如图，四边形 $ABCD$ 由 Rt$\triangle ABC$ 和 Rt$\triangle BCD$ 拼接而成，其中 $\angle BAC = \angle BCD = 90^\circ$，$\angle DBC = 30^\circ$，$AB = AC$，$BC = 2\sqrt3$。将 $\triangle ABC$ 沿 $BC$ 折起。

（1）若 $AD = \sqrt6$，求异面直线 $AB$ 与 $CD$ 所成角的余弦值；

（2）当四面体 $ABCD$ 的表面积最大时，求二面角 $A-BC-D$ 的余弦值。

<summary>参考解答</summary>

<strong>解析：</strong>

由 $\angle BAC = 90^\circ$、$AB = AC$、$BC = 2\sqrt3$ 得 $AB = AC = \sqrt6$；由 $\angle BCD = 90^\circ$、$\angle DBC = 30^\circ$、$BC = 2\sqrt3$ 得

$$CD = BC\tan 30^\circ = 2,\qquad BD = \frac{BC}{\cos 30^\circ} = 4$$

（1）取 $BC$ 中点 $O$。因为 $AB = AC$，所以中线 $AO$ 也是高，$AO \perp BC$，且 $AO = \frac{BC}{2} = \sqrt3$（直角三角形斜边上的中线等于斜边的一半）。折起时 $\triangle ABC$ 绕 $BC$ 转动，故 $A$ 始终在过 $O$ 且垂直于 $BC$ 的平面内。

由 $\angle BCD = 90^\circ$ 得 $\overrightarrow{CD}\cdot\overrightarrow{BC} = 0$。把 $\overrightarrow{BA}$ 沿 $BC$、$CA$ 分解：$\overrightarrow{BA} = \overrightarrow{BC} + \overrightarrow{CA}$，于是

$$\overrightarrow{CD}\cdot\overrightarrow{BA} = \overrightarrow{CD}\cdot\overrightarrow{BC} + \overrightarrow{CD}\cdot\overrightarrow{CA} = 0 + |CD||CA|\cos\angle ACD = 2\sqrt6\cos\angle ACD$$

设异面直线 $AB$ 与 $CD$ 所成角为 $\alpha$，则 $\cos\alpha = \frac{|\overrightarrow{CD}\cdot\overrightarrow{BA}|}{|CD|\cdot|BA|}$，而 $|BA| = \sqrt6$，故 $\cos\alpha = \cos\angle ACD$。

在 $\triangle ACD$ 中 $AC = AD = \sqrt6$，$CD = 2$，由余弦定理

$$\cos\angle ACD = \frac{AC^2 + CD^2 - AD^2}{2\cdot AC\cdot CD} = \frac{6 + 4 - 6}{2\times\sqrt6\times 2} = \frac{1}{\sqrt6} = \frac{\sqrt6}{6}$$

所以异面直线 $AB$ 与 $CD$ 所成角的余弦值为 $\frac{\sqrt6}{6}$。

（2）以 $O$ 为原点：$y$ 轴沿 $OC$ 方向，$x$ 轴在平面 $BCD$ 内且垂直于 $BC$、指向 $D$ 一侧，$z$ 轴垂直于平面 $BCD$，则

$$B(0,-\sqrt3,0),\quad C(0,\sqrt3,0),\quad D(2,\sqrt3,0),\quad A(\sqrt3\cos\theta,\ 0,\ \sqrt3\sin\theta)$$

其中 $\theta = \angle AOx$ 正是二面角 $A-BC-D$ 的平面角，$\theta\in(0,\pi)$。

<img src="/images/20260924_2.svg" width="55%">

四面体中 $\triangle ABC$ 与 $\triangle BCD$ 的面积是定值，分别为 $3$ 与 $2\sqrt3$，所以表面积最大等价于 $\triangle ABD$ 与 $\triangle ACD$ 的面积之和最大，记这两个面积分别为 $S_1$、$S_2$。

由 $\overrightarrow{BA} = (\sqrt3\cos\theta,\ \sqrt3,\ \sqrt3\sin\theta)$、$\overrightarrow{BD} = (2,\ 2\sqrt3,\ 0)$、$\overrightarrow{CA} = (\sqrt3\cos\theta,\ -\sqrt3,\ \sqrt3\sin\theta)$、$\overrightarrow{CD} = (2,\ 0,\ 0)$，用 $S = \frac12\sqrt{|m|^2|n|^2 - (m\cdot n)^2}$ 得

$$S_1 = \sqrt{15 - 3\cos^2\theta - 6\sqrt3\cos\theta},\qquad S_2 = \sqrt{6 - 3\cos^2\theta}$$

记 $u = \cos\theta\in(-1,1)$，把根号内配方：

$$S_1 + S_2 = \sqrt{15 - 3u^2 - 6\sqrt3\,u} + \sqrt{6 - 3u^2} = \sqrt3\left[\sqrt{8 - (u+\sqrt3)^2} + \sqrt{2 - u^2}\right]$$

令 $X = 8 - (u+\sqrt3)^2$，$Y = 2 - u^2$，对 $\sqrt X + \sqrt Y$ 用加权柯西不等式（把 $\sqrt Y$ 写成 $\frac{1}{\sqrt2}\cdot\sqrt{2Y}$）：

$$\sqrt X + \sqrt Y \le \sqrt{\left(1 + \frac12\right)(X + 2Y)} = \sqrt{\frac32(X + 2Y)}$$

再由配方，$X + 2Y = 12 - (u+\sqrt3)^2 - 2u^2 = 10 - 3\left(u + \frac{\sqrt3}{3}\right)^2 \le 10$，于是

$$S_1 + S_2 \le \sqrt3\cdot\sqrt{\frac32\times 10} = \sqrt{45} = 3\sqrt5$$

两处等号可以同时取到：当 $u = -\frac{\sqrt3}{3}$ 时 $X = \frac{20}{3}$、$Y = \frac53$，恰满足加权柯西的取等条件 $X = 4Y$。

所以当 $\cos\theta = -\frac{\sqrt3}{3}$ 时四面体表面积最大（最大值为 $3 + 2\sqrt3 + 3\sqrt5$），故二面角 $A-BC-D$ 的余弦值为 $-\frac{\sqrt3}{3}$。

<strong>答案：</strong>（1）$\displaystyle \frac{\sqrt6}{6}$；（2）$\displaystyle -\frac{\sqrt3}{3}$
