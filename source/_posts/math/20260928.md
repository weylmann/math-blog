## 题目

3. 如图，在圆锥 $SO$ 中，$A$，$B$ 是底面圆 $O$ 上的动点，$BB'$ 是圆 $O$ 的直径，$M$，$N$ 是 $SB$ 的两个三等分点，$\angle AOB = \theta$（$0 < \theta < \pi$），记二面角 $N-OA-B$、$M-AB'-B$ 的平面角分别为 $\alpha$、$\beta$，若 $\alpha \le \beta$，则 $\theta$ 的最大值是（　　）

A. $\dfrac{5\pi}{6}$　　B. $\dfrac{2\pi}{3}$　　C. $\dfrac{\pi}{2}$　　D. $\dfrac{\pi}{4}$

<summary>参考解答</summary>

<strong>解析：</strong>

设底面圆的半径为 $r$，$OS = a$。

以 $B'B$ 所在直线为 $x$ 轴，以垂直于 $B'B$ 的直线为 $y$ 轴，以 $OS$ 所在直线为 $z$ 轴建立空间直角坐标系，则

$$O(0, 0, 0), \quad B(r, 0, 0), \quad S(0, 0, a), \quad A(r\cos\theta, r\sin\theta, 0), \quad B'(-r, 0, 0)$$

因为 $M$，$N$ 是 $SB$ 的两个三等分点，所以

$$M\left(\frac{r}{3}, 0, \frac{2a}{3}\right), \quad N\left(\frac{2r}{3}, 0, \frac{a}{3}\right)$$

<strong>第一步：求二面角 $N-OA-B$ 的平面角 $\alpha$。</strong>

$$\overrightarrow{OA} = (r\cos\theta, r\sin\theta, 0), \quad \overrightarrow{ON} = \left(\frac{2r}{3}, 0, \frac{a}{3}\right)$$

设平面 $NOA$ 的法向量为 $\vec{m} = (x_1, y_1, z_1)$，由 $\vec{m} \cdot \overrightarrow{OA} = 0$ 和 $\vec{m} \cdot \overrightarrow{ON} = 0$ 得

$$\begin{cases} x_1 r\cos\theta + y_1 r\sin\theta = 0 \\ \dfrac{2r}{3} x_1 + \dfrac{a}{3} z_1 = 0 \end{cases}$$

取 $x_1 = 1$，解得 $y_1 = -\dfrac{\cos\theta}{\sin\theta}$，$z_1 = -\dfrac{2r}{a}$，即

$$\vec{m} = \left(1, -\frac{\cos\theta}{\sin\theta}, -\frac{2r}{a}\right)$$

平面 $OAB$ 即底面所在平面，其法向量为 $\vec{n} = (0, 0, 1)$。

由图可知二面角 $N-OA-B$ 为锐二面角，所以

$$\cos\alpha = \frac{|\vec{m} \cdot \vec{n}|}{|\vec{m}|\,|\vec{n}|} = \frac{\dfrac{2r}{a}}{\sqrt{1 + \dfrac{\cos^2\theta}{\sin^2\theta} + \dfrac{4r^2}{a^2}}}$$

<strong>第二步：求二面角 $M-AB'-B$ 的平面角 $\beta$。</strong>

$$\overrightarrow{B'A} = (r + r\cos\theta, r\sin\theta, 0), \quad \overrightarrow{AM} = \left(\frac{r}{3} - r\cos\theta, -r\sin\theta, \frac{2a}{3}\right)$$

设平面 $MAB'$ 的法向量为 $\vec{k} = (x_2, y_2, z_2)$，由 $\vec{k} \cdot \overrightarrow{B'A} = 0$ 和 $\vec{k} \cdot \overrightarrow{AM} = 0$ 得

$$\begin{cases} x_2 r(1 + \cos\theta) + y_2 r\sin\theta = 0 \\ x_2\left(\dfrac{r}{3} - r\cos\theta\right) - y_2 r\sin\theta + \dfrac{2a}{3} z_2 = 0 \end{cases}$$

取 $x_2 = 1$，由第一式得 $y_2 = -\dfrac{1 + \cos\theta}{\sin\theta}$；代入第二式得

$$\frac{r}{3} - r\cos\theta + r(1 + \cos\theta) + \frac{2a}{3} z_2 = 0 \Longrightarrow \frac{4r}{3} + \frac{2a}{3} z_2 = 0 \Longrightarrow z_2 = -\frac{2r}{a}$$

即

$$\vec{k} = \left(1, -\frac{1 + \cos\theta}{\sin\theta}, -\frac{2r}{a}\right)$$

平面 $ABB'$ 即底面所在平面，其法向量同样为 $\vec{h} = (0, 0, 1)$。

由图可知二面角 $M-AB'-B$ 为锐二面角，所以

$$\cos\beta = \frac{|\vec{k} \cdot \vec{h}|}{|\vec{k}|\,|\vec{h}|} = \frac{\dfrac{2r}{a}}{\sqrt{1 + \dfrac{(1 + \cos\theta)^2}{\sin^2\theta} + \dfrac{4r^2}{a^2}}}$$

<strong>第三步：由 $\alpha \le \beta$ 求 $\theta$ 的范围。</strong>

由二面角的范围知 $0 \le \alpha \le \beta \le \pi$，而 $y = \cos x$ 在 $[0, \pi]$ 上单调递减，所以

$$\alpha \le \beta \Longleftrightarrow \cos\alpha \ge \cos\beta$$

两个余弦值的分子相同（都是 $\dfrac{2r}{a}$，且都大于 $0$），故只需比较分母：

$$1 + \frac{\cos^2\theta}{\sin^2\theta} + \frac{4r^2}{a^2} \le 1 + \frac{(1 + \cos\theta)^2}{\sin^2\theta} + \frac{4r^2}{a^2}$$

即 $\cos^2\theta \le (1 + \cos\theta)^2$，也就是 $(1 + \cos\theta)^2 - \cos^2\theta \ge 0$。

而 $(1 + \cos\theta)^2 - \cos^2\theta = 1 + 2\cos\theta + \cos^2\theta - \cos^2\theta = 1 + 2\cos\theta$，所以

$$1 + 2\cos\theta \ge 0 \Longrightarrow \cos\theta \ge -\frac{1}{2}$$

又 $0 < \theta < \pi$，故 $0 < \theta \le \dfrac{2\pi}{3}$。

反过来，当 $\theta = \dfrac{2\pi}{3}$ 时 $\cos\theta = -\dfrac{1}{2}$，此时 $\alpha = \beta$，条件 $\alpha \le \beta$ 恰好取到。

<img src="/images/20260928_2.svg" width="55%">

<strong>答案：</strong>$\displaystyle \frac{2\pi}{3}$（选 B）
