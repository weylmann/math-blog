## 题目

棱长为 $1$ 的正方体 $ABCD-A_1B_1C_1D_1$ 中，$M$、$N$、$P$ 分别为棱 $C_1D_1$、$A_1A$、$BC$ 的中点，$Q$ 为平面 $PMN$ 上的动点，若 $A_1C_1$、$B_1D_1$ 交于 $O_1$，将正方形 $A_1B_1C_1D_1$ 的四个顶点绕着 $O_1$ 在上底面逆时针旋转 $45^\circ$ 得到一个十面体 $ABCD-EFGH$（如图），则下列结论正确的是（　　）

A. 十面体的外接球表面积为 $3\pi$

B. $A_1D \perp MN$

C. 若 $QB_1$ 与 $DB_1$ 的夹角为 $30^\circ$，则 $Q$ 点的轨迹为圆

D. 十面体的体积为 $\frac{2+\sqrt2}{3}$

<summary>参考解答</summary>

<strong>解析：</strong>

设 $AC \cap BD = O$，则 $O$ 为下底面中心、$O_1$ 为上底面中心，$OO_1 \perp$ 两底面且 $|OO_1| = 1$。十面体 $ABCD-EFGH$ 的侧面均为三角形，其八个顶点为 $A$、$B$、$C$、$D$ 与 $E$、$F$、$G$、$H$，其中 $EFGH$ 是正方形 $A_1B_1C_1D_1$ 绕 $O_1$ 在顶面内旋转 $45^\circ$ 所得。

<strong>选项 A：</strong>

取 $OO_1$ 的中点 $T$。由对称性知 $T$ 为十面体外接球的球心。

因为 $|AO| = \frac{\sqrt2}{2}$，$|OT| = \frac12$，所以

$$|AT| = \sqrt{|AO|^2 + |OT|^2} = \sqrt{\left(\frac{\sqrt2}{2}\right)^2 + \left(\frac12\right)^2} = \frac{\sqrt3}{2}.$$

又旋转不改变各顶点到中心的距离，故 $|O_1E| = |O_1F| = |O_1G| = |O_1H| = \frac{\sqrt2}{2}$，同理

$$|TE| = \sqrt{|O_1E|^2 + |O_1T|^2} = \frac{\sqrt3}{2}.$$

所以 8 个顶点到 $T$ 的距离都等于 $\frac{\sqrt3}{2}$，即外接球半径为 $\frac{\sqrt3}{2}$，表面积为

$$4\pi\left(\frac{\sqrt3}{2}\right)^2 = 3\pi,$$

故 A 正确。

<strong>选项 B：</strong>

以 $A$ 为原点，$\overrightarrow{AB}$、$\overrightarrow{AD}$、$\overrightarrow{AA_1}$ 为 $x$、$y$、$z$ 轴建系，则

$$A_1(0,0,1),\quad D(0,1,0),\quad M\left(\frac12,1,1\right),\quad N\left(0,0,\frac12\right).$$

于是

$$\overrightarrow{A_1D} = (0,1,-1),\qquad \overrightarrow{MN} = \left(-\frac12,-1,-\frac12\right),$$

$$\overrightarrow{A_1D} \cdot \overrightarrow{MN} = 0\times\left(-\frac12\right) + 1\times(-1) + (-1)\times\left(-\frac12\right) = -\frac12 \ne 0,$$

所以 $A_1D$ 与 $MN$ 不垂直，B 错误。

<strong>选项 C：</strong>

$Q$ 满足“$QB_1$ 与 $DB_1$ 所成角为 $30^\circ$”，即 $Q$ 在以 $B_1$ 为顶点、$DB_1$ 为轴的圆锥面上（母线与轴夹角 $30^\circ$）。

由 $\overrightarrow{PM} = \left(-\frac12,\frac12,1\right)$，$\overrightarrow{PN} = \left(-1,-\frac12,\frac12\right)$ 得平面 $PMN$ 的一个法向量

$$\overrightarrow{PM} \times \overrightarrow{PN} = \left(\frac34, -\frac34, \frac34\right) \parallel (1,-1,1),$$

而 $\overrightarrow{DB_1} = (1,-1,1)$，故 $DB_1 \perp$ 平面 $PMN$。

又 $B_1(1,0,1)$ 不在平面 $PMN$ 上（平面方程为 $x - y + z = \frac12$，代入得 $2 \ne \frac12$），所以该圆锥面与平面 $PMN$ 的截线是圆，C 正确。

<strong>选项 D：</strong>

在顶面内，分别过 $E$、$G$ 作 $FH$ 的平行线，过 $F$、$H$ 作 $EG$ 的平行线，四线依次相交于 $A_2$、$B_2$、$C_2$、$D_2$，则 $A_2B_2C_2D_2$ 是边长为 $\sqrt2$ 的正方形（它的边与 $EG$、$FH$ 平行），连结 $AA_2$、$BB_2$、$CC_2$、$DD_2$ 得四棱台 $ABCD-A_2B_2C_2D_2$。

该棱台上、下底面边长分别为 $\sqrt2$、$1$，高为 $1$，故

$$V_{ABCD-A_2B_2C_2D_2} = \frac13\left(2 + 1 + \sqrt{2\times1}\right)\times 1 = \frac{3+\sqrt2}{3}.$$

十面体 $ABCD-EFGH$ 与棱台相差顶部四个小四面体，例如 $A-A_2EH$：底面 $\triangle A_2EH$ 是两直角边为 $\frac{\sqrt2}{2}$ 的等腰直角三角形，高为 $1$，故

$$V_{A-A_2EH} = \frac13 \times \frac14 \times 1 = \frac{1}{12},$$

同理 $V_{B-B_2EF} = V_{C-C_2FG} = V_{D-D_2GH} = \frac{1}{12}$。所以十面体的体积为

$$V_{ABCD-A_2B_2C_2D_2} - 4V_{A-A_2EH} = \frac{3+\sqrt2}{3} - 4\times\frac{1}{12} = \frac{2+\sqrt2}{3},$$

D 正确。

<strong>答案：</strong>$\displaystyle \mathrm{ACD}$
